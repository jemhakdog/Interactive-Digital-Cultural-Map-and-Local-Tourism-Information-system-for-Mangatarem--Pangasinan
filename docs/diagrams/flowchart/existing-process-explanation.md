# Explanation: Existing Process Flowchart (Bottlenecks)

This flowchart visualizes the legacy method of data collection used prior to the implementation of the Digital Cultural Map system.

### Process Breakdown:
1.  **Manual Field Surveys**: Barangay personnel physically visit sites and fill out paper-based forms (specifically Forms 01A to 07) designated for cultural mapping.
2.  **Encoding Phase**: Collected physical data is manually typed into digital documents like Word or Excel. This is identified as a primary **Bottleneck** due to risks of human error and time consumption.
3.  **Physical Submission**: Data is submitted through traditional channels (Barangay Dashboard or physical handovers).
4.  **Verification Loop**: Content undergoes a manual approval process. If rejected, it must be returned to the Barangay level for correction, causing significant delays.
5.  **Data Silos**: Once approved, data is stored in localized databases which are not easily accessible for real-time public exploration.

### Strategic Goal:
The implementation of the Digital Cultural Map aims to automate the encoding and submission steps, transforming this fragmented manual process into a streamlined digital workflow.
