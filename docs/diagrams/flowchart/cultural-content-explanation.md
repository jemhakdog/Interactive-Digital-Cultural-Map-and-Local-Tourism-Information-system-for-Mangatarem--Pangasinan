# Explanation: Cultural Content Flowchart

This flowchart illustrates the navigation path for users to access various cultural assets within the Mangatarem Digital Map.

### Key Logic Steps:
1.  **Entry Point**: The process begins at the **Public Index**, which serves as the primary dashboard for all users.
2.  **Modular Choice**: Users interact with a navigation menu to choose between three primary content streams:
    - **Events**: Catalogs local festivities, historical celebrations, and town activities.
    - **Gallery**: Displays high-quality media (images/videos) showcasing the town's beauty.
    - **Heritage**: Provides deep educational content regarding tangible (landmarks, architecture) and intangible (traditions, folklore) town heritage.
3.  **Discovery Layer**: For Heritage content, an additional filtering step allows users to browse by specific categories (e.g., Natural vs. Built Heritage) before viewing individual items.
4.  **Admin Oversight**: The "Approved" status is a mandatory prerequisite for all items listed in these views, ensuring only verified and high-quality cultural data is presented to the public.
