# User Manual

Welcome to the Interactive Digital Cultural Map for Mangatarem! This guide will help you navigate and explore the rich cultural heritage and tourism attractions of our municipality.

## Getting Started

### Accessing the Platform
Visit the application URL (e.g., `https://mangatarem-cultural-map.vercel.app`) in any modern web browser.

### The Homepage
The homepage provides a quick overview of featured attractions, upcoming events, and a quick link to the main Interactive Map.

### Progressive Web App (PWA) Support

This platform can be installed on your device like a native app:

**On Mobile (Android/iOS)**:
1. Open the site in your browser
2. Look for "Add to Home Screen" prompt or tap the browser menu
3. Select "Add to Home Screen" or "Install App"
4. The app icon will appear on your home screen

**On Desktop (Chrome/Edge)**:
1. Look for the install icon (⊕) in the address bar
2. Click "Install" when prompted
3. The app will open in its own window

**Benefits of Installing**:
- Faster loading times (cached resources)
- Offline access to previously visited pages
- Full-screen experience without browser UI
- App-like interface

## Exploring the Map

1. **Navigate to the Map**: Click on the "Map" or "Explore" link in the navigation bar.
2. **Interact with Markers**:
   - Click on any pin on the map to see the name of the attraction.
   - Click "View Details" in the popup to learn more about the location.
3. **Barangay Highlights**: Select a specific barangay from the list or map to see its unique cultural assets and history.

## Attractions and Events

### Tourism Attractions
- Browse through categories like **Nature**, **Historical**, and **Religious**.
- Read descriptions, view photos, and see the exact location of each spot.

### Local Events
- Stay updated with Mangatarem's festivals and community celebrations.
- Check dates, locations, and descriptions for upcoming activities.

## User Interaction

### Account Creation
While much of the platform is public, creating an account allows you to:
- **Favorite** locations to save them for later.
- **Review** and rate attractions you've visited.

### Submitting Content
If you have a photo or information about a cultural spot you'd like to share, refer to the [Contributor Guide](file:///d:/porjects/Interactive-Digital-Cultural-Map-and-Local-Tourism-Information-system-for-Mangatarem--Pangasinan/docs/contributor_guide.md) for detailed instructions on how to contribute content.
