Functional Testing
Purpose: To verify if the system’s features work as intended based on requirements.
How to Execute:
1. Create Test Cases – Define multiple test scenarios that specify the expected
behavior or outcomes for each system feature.
2. Perform Manual Testing – Execute the test cases by interacting with the system
as an end-user.
3. Document the Results – Record whether each test case Passed or Failed, noting
any errors or unexpected behaviors for further debugging and improvement.
* Start by explaining the significance of functional testing, emphasizing its role

Usability Testing
Purpose: To verify the system’s user-friendliness and ease of navigation.
How to Execute:
1. Design a Usability Survey Form – Create a structured questionnaire that
assesses key usability aspects, such as ease of use, system efficiency, and
interface design. Use a Likert Scale (1-5 rating) to measure user satisfaction.
2. Conduct User Interaction – Allow expected users (e.g., target audience or
stakeholders) to explore and interact with the system. Ensure they perform
essential tasks to simulate real-world usage.
3. Collect User Feedback – Ask participants to complete the survey form based on
their experience. Encourage additional comments for qualitative insights.
* Start by explaining the significance of usability testing, emphasizing its role in
ensuring that the system is user-friendly, intuitive, and accessible to its intended users.
* Explain the evaluation criteria, for example: ease of use, interface design,
system responsiveness, and user satisfaction.
