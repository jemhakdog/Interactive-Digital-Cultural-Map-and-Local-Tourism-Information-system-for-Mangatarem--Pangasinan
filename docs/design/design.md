# GoMangatarem Design System

The visual identity of GoMangatarem is rooted in the lush greenery of Mangatarem's landscapes and the warmth of its cultural heritage. This document defines the design tokens and principles for the platform.

## 🎨 Color Palette

### Primary (Nature & Heritage)
- **Forest Green**: `#14532D` (Deep, grounding)
- **Lush Accents**: `#22C55E` (Vibrant, growth)
- **Soil Brown**: `#451A03` (Earth, roots)

### Secondary (Atmosphere)
- **Sky Tint**: `#F0F9FF` (Light, airy)
- **Cloud Gray**: `#F9FAFB` (Neutral background)
- **Deep Slate**: `#111827` (Text & high contrast)

### Surfaces
- **Glass**: `rgba(255, 255, 255, 0.7)` (Backdrop-blur: 12px)
- **Paper**: `#FFFFFF` (Solid components)

## ✍️ Typography

- **Headings**: `Outfit` or `Inter` (Sans-serif, Bold, Tracking: -0.025em)
- **Body**: `Inter` (Sans-serif, Regular/Light, Leading: 1.625)

## ✨ UI Principles

### 1. Glassmorphism
Use backdrop blur for floating UI elements like filters, navigation, and overlays.
- `backdrop-blur-md`
- `bg-white/70`
- `border border-white/20`

### 2. Micro-animations
- **Entrance**: Subtle fade-in with slide-up for grid items.
- **Hover**: Scale `105%` for images, button transitions (300ms).
- **Parallax**: Gentle scroll-linked movement for hero backgrounds.

### 3. Masonry Layout
Embrace the "natural" flow of content. Avoid rigid grids for media galleries; use organic spacing and variable heights.
