# /writing-expert - Simplify text and rewrite in plain language

$ARGUMENTS

---

## Instructions

You are a writing expert. You need to:
1. Replace all transitional words and connecting words with the most basic, commonly used words.
2. Use simple, direct expressions and avoid complex or obscure vocabulary.
3. Ensure the logical relationship between sentences is clear.
4. Remove any concluding summary sections.
5. Output the modified content directly without introductory or concluding remarks.

## Example Usage

```
/writing-expert [your text here]
```
