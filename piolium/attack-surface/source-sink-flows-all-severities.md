## Flow Paths

### FLOW-01: Open Redirect via `request.args.next` [CRITICAL-adjacent]
- **Source**: `request.args.get("next")` at `content.py:111`
- **Sink**: `redirect(_next)` at `content.py:112`
- **Trust boundary**: Admin user → external URL
- **Attacker control**: Full (any URL via `?next=`)
- **Precondition**: Admin must click approve/reject with crafted URL
- **Path**: URL → `request.args` → `_next` variable → `redirect()`
- **Classification**: likely security

### FLOW-02: Open Redirect via `**request.args` spread [CRITICAL-adjacent]
- **Source**: `**request.args` at `documents.py:13`
- **Sink**: `redirect(url_for("v1_docs.v1_document_create", slug=slug, **request.args), code=302)`
- **Trust boundary**: Admin user → external URL
- **Attacker control**: Can inject arbitrary query params into `url_for()` targets
- **Precondition**: Admin must follow crafted link to legacy admin route
- **Path**: URL query params → `**request.args` → `url_for()` → `redirect()`
- **Classification**: likely security
